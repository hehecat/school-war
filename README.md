# 校园战争：重制版（Web MVP）

四个社团在校园里抢地盘的实时策略小游戏。基于《校园战争：重制版》GDD v0.3 实现的可玩 MVP：
Three.js 斜俯视沙盘、实时占领与战斗、4 个 AI 对手、9 张地图、卡牌/道具/事件，以及 WebSocket 联机房间。

## 跑起来

```bash
npm install
npm run dev        # 开发：Vite + 本地联机服务（默认 http://localhost:5173）
npm run build      # 生产构建
npm test           # 规则 / 地图 / 联机测试
```

生产模式跑联机服务：

```bash
PORT=5175 NODE_ENV=production npx tsx server.ts
```

## 怎么玩

- **出兵**：点自己的格子选为出兵格 → 点目标格出击；也可以直接从己方格拖到目标格。占敌方格子就是攻城。
- **框选**：在空白处拖出方框，选中多格后点目标格一起出击。
- **视野**：右键拖动、WASD / 方向键、滚轮缩放。
- **目标**：8 分钟内占格最多者胜；也可以直接占领 60% 校园速胜。
- **社团**：紫（武斗派）/ 黄（体育生）/ 绿（人海）/ 黑（学生会），各有被动与自动施放的社团技能。

## 目录

| 路径 | 说明 |
| --- | --- |
| `src/core.ts` | 规则内核：格子、兵团、战斗、产出、卡牌、事件、胜负（可独立测试） |
| `src/map-rules.ts` | 各张地图的专属规则（停电、宿舍翻墙、雪天、考试…） |
| `src/scene.ts` | Three.js 沙盘渲染与鼠标/触摸交互 |
| `src/main.ts` | 界面、面板、开局流程、联机大厅 |
| `src/net.ts` / `server.ts` | WebSocket 客户端与权威服务端（房间码、20Hz 同步、断线重连） |
| `src/*.test.ts` | 33 项测试 |

## 状态

教学区 16×16 与 9 张地图可用；本地四人混战 / 组队 2v2 / 联机房间均可玩。
